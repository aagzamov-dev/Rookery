macOS one extra step

  1. Open the .dmg and drag Rookery to Applications.
  2. Run this once in Terminal:
    xattr -dr com.apple.quarantine "/Applications/Rookery.app"
  3. Open Rookery.

Questions

Is Rookery free?

Yes. Free and open source under the MIT license.

Does it send my data anywhere?

No. It only connects to your own servers. Sync between your computers uses a folder you choose.

Why does macOS say the app is damaged?

Apple shows this for apps without a paid developer account. Run the command from Install once and it opens normally.

Can I bring my servers from MobaXterm or PuTTY?

Yes. The welcome screen imports MobaXterm, PuTTY and ~/.ssh/config.

Is there a Linux or phone version?

Not yet. Windows and macOS for now.

Rookery for macOS (.dmg) · Download again

  1. Open the .dmg and drag Rookery to Applications.
  2. Open Terminal and run this once:
    xattr -dr com.apple.quarantine "/Applications/Rookery.app"
  3. Open Rookery. Updates install by themselves after this.
Why this step?

Apple warns about apps that aren’t signed with a paid Apple Developer account. Rookery doesn’t have one yet, so macOS may call it “damaged”. It isn’t.

The command only removes the “downloaded from the internet” mark from Rookery. Rookery is open source and built by GitHub from its public code.
